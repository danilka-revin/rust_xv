# Станция отношений — XIAO ESP32-C6 + Круглый экран GC9A01A

Маленький хранитель нашей любви: компактное устройство с таймером отношений (с **21 октября 2026**), плавной 3D-анимацией сердечка на круглом экране `240×240` без мерцания, переливающимся мини-сердечком на секундной орбите, **удалёнными открытками и посланиями через интернет (`ntfy.sh`)**, **4-й страницей погоды с «ГУЛЯБЕЛЬНО ❤» в любую погоду** и **автообновлением прошивки по воздуху с GitHub (HTTPS OTA)**.

---

## ⚡ Как прошить плату в первый раз по USB-C (Arduino IDE 2.x)

Поскольку автообновление (OTA) уже встроено внутрь самой прошивки, **подключить плату проводом нужно только один раз сейчас** — дальше она сможет обновляться сама по Wi-Fi.

1. **Скачай и установи Arduino IDE 2.x** с официального сайта [`arduino.cc`](https://www.arduino.cc/en/software).
2. **Добавь поддержку ESP32 в Arduino IDE:**
   - Открой **`File → Preferences`** (Настройки).
   - В поле **Additional Boards Manager URLs** вставь ссылку:
     ```
     https://espressif.github.io/arduino-esp32/package_esp32_index.json
     ```
   - Нажми `OK`, затем открой **`Tools → Board → Boards Manager...`**, найди **`esp32`** (автор *Espressif Systems*) и установи актуальную версию (3.x).
3. **Установи 2 библиотеки экрана:**
   - Открой **`Sketch → Include Library → Manage Libraries...`** (иконка книг слева).
   - Найди и установи:
     - **`Adafruit GFX Library`** (если попросит установить зависимости вроде `Adafruit BusIO` — нажми *Install all*).
     - **`Adafruit GC9A01A`**
4. **Открой скетч проекта:**
   - Открой файл **`love_gift_esp32c6/love_gift_esp32c6.ino`** в Arduino IDE (рядом в той же папке обязательно должны лежать `cyrillic_font.h`, `love_card.h` и `web_ui.h` — IDE откроет их вкладками автоматически).
5. **Выбери плату и схему разделов (ВАЖНО для открыток и OTA!):**
   - Подключи **Seeed Studio XIAO ESP32-C6** к компьютеру кабелем USB-C *(кабель должен передавать данные, не только зарядку!)*.
   - **`Tools → Board → esp32 → XIAO_ESP32C6`**
   - **`Tools → Port`** → выбери появившийся COM-порт (на Windows `COM...`, на Mac `/dev/cu.usbmodem...`, на Linux `/dev/ttyACM0`).
   - **`Tools → Partition Scheme → Default 4MB with spiffs`** *(обязательно! Это даёт 2 OTA-слота для автообновлений с GitHub + место `LittleFS` под 5 открыток)*.
6. **Нажми кнопку `Upload` (стрелка `→` вверху слева).**
   - *Если вдруг загрузка не стартует:* зажми кнопку **`BOOT`** на плате XIAO, кратко нажми **`RESET`**, отпусти **`BOOT`** и снова нажми `Upload`.
7. **Готово!** На экране побежит красивое кольцо загрузки, затем появится открытая Wi-Fi сеть **`love`**. Подключись к ней с телефона, открой `192.168.4.1` (или оно откроется само), выбери домашний Wi-Fi и введи пароль — он сохранится в памяти навсегда.

## 📂 Файлы проекта

Папка **`love_gift_esp32c6/`** (все 4 файла должны лежать в одной папке):
- `love_gift_esp32c6.ino` — основная прошивка (`v1.3.0`): буферы `GFXcanvas16` без мерцания, плавные анимации переключения 4 страниц по Кнопке 2, постоянное хранение Wi-Fi, города погоды и последних 5 открыток/посланий в NVS + LittleFS, фоновый опрос `ntfy.sh` и Open-Meteo, отправка ответного сердечка и GitHub OTA.
- `love_card.h` — декодер полноэкранных круглых открыток `LVC1` (QOI565) и хранение в `LittleFS`.
- `cyrillic_font.h` — встроенный кириллический шрифт 5×7 (UTF-8, `°`, `—`/`–`, `•` и встроенное мини-сердечко для `❤️` / `♥`).
- `web_ui.h` — встроенный сайт станции с двумя вкладками (**«1. Наше время»** и **«2. Послания»**), рендером открыток, выбором города для погоды и настройками Wi-Fi / OTA.

Папка **`sender/`**:
- `index.html` — твой **удалённый конструктор открыток во весь круглый экран (`240×240`)**: загрузка и масштабирование/поворот фото, несколько текстовых блоков в любом месте с разными шрифтами, эмодзи, фото-стикеры и отправка через `ntfy.sh` из любой точки мира.

Папка **`ota/`** (для автообновлений через GitHub):
- `version.json` — манифест актуальной версии прошивки и ссылки на `.bin`.
- `prepare_ota.py` — удобный скрипт для подготовки новой версии за одну команду.

## 💌 Страницы экрана и удалённые открытки (`ntfy.sh`)

Используется бесплатный облачный канал **`ntfy.sh`** с твоим приватным топиком (по умолчанию `love_station_xv_7d92a4c8e1` в `.ino` и `sender/index.html`).

На **Кнопку 2 (`D1`)** она всегда может листать **4 страницы** с плавной анимацией:
1. **Страница 1**: Таймер отношений (с 21 октября 2026), дни, `ЧЧ : ММ : СС`, бегущая строка и переливающееся орбитальное сердечко.
2. **Страница 2**: Полноэкранная круглая открытка или твоё текстовое послание (сохраняются в энергонезависимую память).
3. **Страница 3**: Красивое 3D-сердечко, статус Wi-Fi, IP-адрес сайта и версия прошивки.
4. **Страница 4**: Краткая погода выбранного города (анимированная иконка, температура, описание, ветер) и **«ГУЛЯБЕЛЬНО ❤»** в любую погоду! Город можно выбрать в настройках на сайте станции (по умолчанию — Москва).

### Ответное сердечко от неё:
- Когда она нажимает **Кнопку 1 (`D0`)** на станции (или кнопку **«❤️ Отправить сердечко в ответ»** на сайте), станция публикует уведомление в канал `<твой_топик>_reply` — оно сразу появляется в `sender/index.html` и в приложении `ntfy` на телефоне.

## 🔄 Как работает автообновление с GitHub (и как выкатить обнову)

Устройство само проверяет `ota/version.json` на GitHub в фоновой задаче (через 45 секунд после включения и далее **каждые 30 минут**, а также по кнопке «Проверить обновление» в настройках на сайте). Пока идёт проверка, экран продолжает плавно работать без единого фриза.

> **Важно:** чтобы станция у девушки дома могла скачивать обновления без пароля, репозиторий на GitHub должен быть **Public** (публичным).

### Как выпустить обновление (2 способа — вообще без проводов!):

#### Способ А — Полный автомат через GitHub Actions
Готовый шаблон workflow лежит в **`ota/github_workflow_build_ota.yml`** (при желании скопируйте его в `.github/workflows/build_ota.yml` прямо через веб-интерфейс GitHub — токен интеграции не имеет права создавать workflow-файлы автоматически):
1. Поменяйте код в `love_gift_esp32c6/` и увеличьте `#define FIRMWARE_VERSION "1.4.0"` в `.ino`.
2. Сделайте `git push` в ветку `main`.
3. GitHub сам скомпилирует прошивку под `XIAO ESP32-C6`, выложит `ota/firmware.bin` и обновит `ota/version.json`.
4. Станция сама скачает обновление по Wi-Fi, перепрошьётся и перезагрузится с новым кодом (не теряя пароль от Wi-Fi).

#### Способ Б — Вручную из Arduino IDE
1. Поднимите `#define FIRMWARE_VERSION`.
2. **`Sketch → Export Compiled Binary`** → скопируйте `love_gift_esp32c6.ino.bin` *(не `.merged.bin`)* в `ota/firmware.bin`, обновите `ota/version.json` (или запустите `python3 ota/prepare_ota.py 1.4.0`) и сделайте `git push` в `main`.

## 🔌 Схема подключения

| Компонент | Пин модуля | Пин XIAO ESP32-C6 | GPIO |
|---|---|---|---|
| Экран GC9A01A `SCK / CLK` | SCL | D8 (SCK) | `GPIO 19` |
| Экран GC9A01A `MOSI / SDA` | SDA | D10 (MOSI) | `GPIO 18` |
| Экран GC9A01A `CS` | CS | D3 | `GPIO 21` |
| Экран GC9A01A `DC` | DC | D4 | `GPIO 22` |
| Экран GC9A01A `RST` | RES | D5 | `GPIO 23` |
| Экран GC9A01A `VCC / GND` | VCC / GND | `3V3` / `GND` | — |
| Кнопка 1 (Ответное ❤️ / Тёплая фраза) | — | D0 | `GPIO 0` (нажатие = `HIGH`) |
| Кнопка 2 (Листать 4 страницы / Сброс Wi-Fi) | — | D1 | `GPIO 1` (нажатие = `HIGH`) |
| Аккумулятор `18650` (3.7V Li-Ion) | `+` / `-` | Контакты `BAT+` и `BAT-` снизу платы XIAO | Заряжается от USB-C XIAO |
